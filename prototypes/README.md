# Hardware & Software Prototypes

This directory holds all physical and software prototype work — from early concepts and design documents to working code and hardware experiments.

## Subdirectories

- `grok-launcher/` — Rust + egui cross-platform launcher and monitoring tool (high priority)
- `soilnova/` — Soilnova environmental / sensing prototype line
- `vista-nova/` — Vista Nova visual / display prototype line
- `york-autotype/` — York Autotype automation / typing prototype concepts
- `hardware-monitoring/` — Shared monitoring, sensor pipelines, and edge tooling

See the detailed `grok-launcher/README.md` and `docs/roadmap.md` for current priorities.
