# Shared Tools & Utilities

Reusable tools, scripts, monitoring infrastructure, and development utilities that support multiple areas of NexusSpace.

## Subdirectories

- `monitoring/` — Dashboards, logging, alerting, and observability tooling (mesh, agents, hardware, blockchain)

These tools are intended to be shared across `mesh-networking/`, `ai-agents/`, `prototypes/`, and `blockchain/`.
