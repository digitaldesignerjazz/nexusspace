# Blockchain Layer

**XCoin / QCoin + Integrations with Mesh**

The blockchain and token layer provides coordination, verifiable history, value transfer, and on-chain governance that complements the mesh networking substrate.

## Subdirectories

- `xcoin/` — XCoin core and ecosystem
- `qcoin/` — QCoin core and ecosystem
- `integrations/` — Bridges and interactions between QNET mesh and blockchain layers

## Current Focus
- Tokenomics and rune systems
- Practical integration between mesh state and on-chain data
- Testnet / simulation environments
- Corporate and legal wrappers that support decentralized infrastructure

See `docs/current-state.md` and the integrations folder for the current bridge vision.
