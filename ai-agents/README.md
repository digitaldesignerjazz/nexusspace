# AI Agents, Swarms & Self-Improving Systems

This is the intelligence and adaptation layer of NexusSpace.

Multi-agent swarms, emotional AI, long-term memory systems, low-level neural architectures, and their integration with mesh networking and blockchain.

## Subdirectories

- `swarms/` — Multi-agent orchestration and swarm behaviors
- `emotional-ai/` — Emotional models, personality, and human-like interaction
- `assembler-nets/` — Low-level / assembler-inspired neural architectures
- `grok-liaura/` — Grok/Liaura-inspired agent frameworks and experiments
- `memory-systems/` — Persistent, long-context memory backends and retrieval

## Current Focus
- Swarm coordination and long-running task execution
- Emotional depth and measurable interaction quality
- Memory persistence across sessions and nodes
- Early integration with mesh state and on-chain data

Creative use of swarms for narrative generation is also actively explored in `creative/`.
